# Explore With Me - Платформа для событий и мероприятий

Контейнеризованное микросервисное приложение для создания мероприятий, управления участием и сбора статистики просмотров.

## О проекте

Explore With Me - это платформа, где пользователи могут создавать, находить и участвовать в мероприятиях. Система включает сбор статистики просмотров и рейтинговую систему для определения популярности событий.

## Архитектура

Проект реализован по микросервисной архитектуре и состоит из двух основных сервисов:

### Основной сервис (Ewm Service)
- Управление событиями и заявками на участие
- Ролевая модель пользователей
- Модерация контента
- Система рейтингов

### Сервис статистики (Stats Service)
- Сбор и хранение статистики просмотров
- Аналитика популярности событий
- API для получения статистических данных

## Ролевая модель

### Администраторы
- Модерация заявок на мероприятия
- Публикация/отклонение событий
- Управление подборками событий
- Удаление пользователей

### Авторизованные пользователи
- Создание и редактирование событий
- Подача заявок на участие
- Оставление оценок
- Просмотр статистики своих событий

### Неавторизованные пользователи
- Просмотр каталога событий
- Поиск и фильтрация мероприятий
- Просмотр рейтингов

## Функциональность

### Управление событиями
- Создание и редактирование мероприятий
- Модерация событий администраторами
- Система статусов (PENDING, PUBLISHED, CANCELED)
- Категоризация событий

### Система участия
- Подача заявок на участие
- Подтверждение/отклонение заявок
- Ограничение количества участников
- Управление статусами заявок

### Статистика и аналитика
- Сбор статистики просмотров событий
- Расчет рейтингов популярности
- Фильтрация по датам и событиям
- API для доступа к статистике

### Поиск и фильтрация
- Расширенный поиск по категориям
- Фильтрация по дате, статусу
- Текстовый поиск в описаниях
- Сортировка по рейтингу и дате

## Технологический стек

### Backend
- **Java** - основной язык разработки
- **Spring Boot** - фреймворк для создания микросервисов
- **Spring MVC** - построение REST API
- **Hibernate** - ORM для работы с базой данных
- **PostgreSQL** - реляционная база данных

### Инфраструктура
- **Docker** - контейнеризация приложения
- **Docker Compose** - оркестрация многоконтейнерного приложения
- **Микросервисная архитектура** - разделение на независимые сервисы

### Инструменты разработки
- **REST API** - архитектура взаимодействия сервисов
- **Postman** - тестирование API endpoints
- **JUnit** - модульное тестирование
- **Mockito** - создание мок-объектов для тестирования
